# sdd-frl Codex App 设置提示词模板

生成的设置提示词必须满足：

1. 从用户当前消息读取且只读取一个分析目标；缺失时只询问分析目标，不猜测、不扫描。
2. 多个目标不能合并到一个任务；要求用户选择一个后停止设置。
3. 运行频率默认每天，运行时间默认 `22:00`。
4. 当前目录是内部固定运行目录，不询问，也不在确认卡或完成回复中展示。
5. 用户确认后创建本地项目定时任务，任务执行
   `sdd-frl prepare . --target "<目标绝对路径>"`。
6. 后续阶段只按 handoff（交接数据）的 `next_action` 路由，并由 CLI 的 Schema
   （结构约束）和运行身份校验决定是否继续。
7. 确认卡和完成回复只包含分析目标、运行频率、运行时间及启用状态。

设置阶段不访问目标会话。目标可访问性和会话匹配由每次任务运行如实判定。
