## 生产启用前仍需配置

- 实际项目根目录、marker 或 conversation ID；
- 每个项目的 `improvement_target_ids`；
- 真实载体路径及稳定 ID；
- 定时表达式和生产时区；
- 保留期限和项目专用脱敏规则。

历史旧结构运行保留，但不会进入新趋势。首次生产运行后应抽查任务切分、显式排除、
验收条件和交互事件是否符合业务预期。
